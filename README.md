## Что здесь


Проект подключается к учебной базе ПРАЙМ и считает метрики по персональному
участку — сессиям пользования сервисами на устройствах desktop за май 2026
года (таблица `service_usage`). В ноутбуке `notebooks/hw1.ipynb` считаются базовые показатели сегмента, строится разбивка активности по дням недели, ищутся пиковые дни, применяется поправка на коэффициенты дней недели, а также проводятся два дополнительных исследования — насколько можно доверять выборке в 1000 человек и чем отличаются друг от друга сегменты различных устройств.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

| Путь | Что это |
|---|---|
| `src/prime/` | код проекта: подключение, метрики |
| `notebooks/` | ноутбуки: разведка, расчёты, графики |
| `pyproject.toml` | какие библиотеки нужны проекту |
| `uv.lock` | какие версии встали на самом деле |
| `.env.example` | образец файла с доступами; настоящий `.env` в репозиторий не идёт |
