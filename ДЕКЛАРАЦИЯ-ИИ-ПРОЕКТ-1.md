## Что я проверил сам
- Проверила, что гипотезы связаны с бизнес-вопросом и их можно проверить на данных
- Перезапустила ноутбук с нуля на чистом ядре (Restart -> Run All): все ячейки выполняются без ошибок, графики строятся.
- Период и объем данных: 3 147 409 платежей с 06.01.2025 по 30.08.2026, считаю по всей схеме `prime`, без сегмента из ДЗ.
- Число строк до и после соединения платежей с подписками совпадает (3 147 409 и 3 147 409), платежей без подписки нет.
- Проверила, что соединение платежей с ценой по интервалу дат добавляет 332 166 лишних строк, поэтому цену беру из суммы платежа.
- Выручка витрины совпадает с выручкой из разведки за вычетом двойных списаний во всех 18 месяцах (assert в ноутбуке).
- По каналам привлечения активные, ушедшие, выручка, платящие подписки и расходы сходятся с общими итогами (assert).
- Сумма влияний в обеих декомпозициях равна изменению показателя (assert), вывод не меняется при другом порядке подстановок.
- Сверила цифры из ноутбука с отдельными разведочными таблицами: выручку по месяцам, отток по каналам, CAC каналов.
- Посмотрела, какие суммы реально списывали в 2026 году: до марта только 199 и 399 руб., с марта только 249 и 449 руб., ни одного списания по 429 руб. из справочника.
- Сверила числа в записке и в выводе ноутбука
