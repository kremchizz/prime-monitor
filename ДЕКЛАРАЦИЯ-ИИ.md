## Что я проверил сам

Пересчитывала ключевые числа вручную, чтобы убедиться, что код действительно
делает, что должен: сумму по `RAW` в задаче 7, распределение по дням недели
в задаче 3 (сверяла с исходными суммами), формулу декомпозиции value на
участника в исследовании Б (проверила, что три фактора действительно
перемножаются в итоговое число). Перепроверяла построчно логику SQL-запросов
в обоих исследованиях — разбирала, что делает каждая часть запроса (агрегаты,
`join`, `group by`). Каждый раз после изменений
запускала `Kernel → Restart Kernel and Run All Cells`, чтобы убедиться, что
ноутбук проходит от начала до конца без ошибок — не только последняя
изменённая ячейка, а весь код целиком. Сверяла результаты между связанными
задачами: например, пиковые дни из задачи 5 использовала для проверки
накопления суммы в задаче 6. Анализировала полученные значения и формулировала итоговые выводы для контрольных задач. После каждого коммита
проверяла `git log` и `git status`, чтобы изменения действительно
сохранились в нужной ветке и ничего не потерялось при работе
с несколькими Codespaces.
